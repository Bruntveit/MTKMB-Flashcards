# MTKMB Flashcards

Anki-kortstokkane eg brukar på MTKMB (materialteknologi) ved NTNU. Korta er laga frå mine eigne forelesingsnotat og pensum, og filene blir oppdaterte automatisk kvar kveld frå Obsidian-vaulten min.

## Kortstokkar

| Fil | Stokk i Anki | Innhald |
|---|---|---|
| `TMA4400 Matematikk – hovudstokk.csv` | TMA4400 | Lineær algebra, komplekse tal, grenser, derivasjon, ODE, numerikk |
| `TMA4400 Matematikk – integrasjon og formlar.csv` | TMA4400 – småting | Standardintegral, integrasjonsmetodar, volum og buelengd, formlar |
| `TMA4400 Matematikk – cloze.csv` | TMA4400 – småting | Cloze-kort laga direkte i Anki (notetypen `MTKMB-cloze`) |
| `TMT4111 Kjemi.csv` | TMT4111 | Gassar, likevekt, syre–base, termodynamikk, løyselegheit |
| `TMT4125 Materialteknologi – hovudstokk.csv` | TMT4125 | Krystallstruktur, defektar, diffusjon, materialklassar, mekaniske eigenskapar |
| `TMT4125 Materialteknologi – eigne notat.csv` | TMT4125 – ny stokk | Same fag frå eigne notat, pluss brot, utmatting, fasediagram og faseomvandling |
| `TMT4125 Materialteknologi – formlar.csv` | TMT4125 Materialteknologi – formlar | Formlane i faget: tettleik, vakansar, Fick, Arrhenius m.m. |
| `TDT4110 Informasjonsteknologi grunnkurs.csv` | TDT4110 | Python: typar, kontrollstrukturar, funksjonar, lister, ordbøker, filer, unntak |

`Arkiv/` har filer som ikkje er aktive stokkar. Dei skal ikkje importerast.

## Importere i Anki

1. Opne fila her og trykk *Download raw file*.
2. I Anki: **Fil → Importer** og vel fila. Kortstokken blir vald automatisk.
3. Korta er laga for notetypen `MTKMB-kort` med felta *Spørsmål, Svar, Kvifor, Felle, Kjelde*.
   Har du han ikkje, vel **Basic** og kople *Spørsmål* → *Front* og *Svar* → *Back*.
4. Importer fila på nytt seinare for å få nye og retta kort. Kvart kort har ein fast ID, så kort som alt finst, blir oppdaterte i staden for dobla.

Formlar er skrivne i MathJax (`\( … \)`), som Anki viser direkte.
Kjelde-feltet lenkjer til notata mine i Obsidian, så dei lenkene verkar berre hos meg.
